# User Launch Checklist - Eternal Digital Assets

**Your one-time setup to launch the passive income system.**

Do these steps in order. Most are one-time only.

## Phase 1: Prepare Your Assets (15-20 mins)

- [ ] Open your Canva folder: Search for "Eternal Digital Assets Hub"
- [ ] For each bundle, click **Share > Download** as PDF (high quality)
- [ ] Also copy the **Shareable link** (editable version) for each
- [ ] Create a folder on your computer: `Eternal-Digital-Assets-Exports`
- [ ] Save all PDFs inside
- [ ] Create one big ZIP called `Ultimate-Mega-Bundle.zip`

## Phase 2: Set Up Sales Platform (10 mins)

- [ ] Go to https://gumroad.com and create account (free)
- [ ] Create new product: **Ultimate Mega Bundle**
  - Price: Start at $99 (launch price) or $119
  - Description: Use the text from README or BUNDLES.md
  - Upload the ZIP file
  - Enable instant delivery + commercial license
- [ ] (Optional but recommended) Create 3-4 individual bundle products at $29-$49 each

## Phase 3: Automation Setup (15-20 mins)

### Option A: Zapier (Easiest)
- [ ] Go to https://zapier.com (free plan is enough)
- [ ] Create Zap 1:
  - Trigger: New Sale in Gumroad
  - Actions:
    1. Add row to Google Sheet (create a "Sales Log" sheet)
    2. Send email via Gmail (thank you + upsell link)
    3. Post to X (use pre-written promo text)

### Option B: Make.com (More powerful)
- Similar setup, more control over multi-step scenarios.

## Phase 4: Traffic & Promotion (One-time batch)

- [ ] Create Pinterest business account: https://www.pinterest.com
- [ ] Sign up for Tailwind (or free alternative) for scheduling
- [ ] Create 15-20 simple pins in Canva using your template mockups
- [ ] Schedule pins to post 3-5x per week linking to your Gumroad

- [ ] Go to your repo: https://github.com/hngzndkpzy-png/eternal-digital-assets
